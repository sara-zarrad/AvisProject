# AvisProject
I-Motion Club Tunisia – Application web de gestion et d’évaluation des séances EMS.

Cette application permet aux membres de découvrir les centres I-Motion, consulter les séances et coachs, puis évaluer leur expérience à travers une note et un avis. Elle propose également un espace administrateur permettant de gérer les centres, les séances, les coachs et les avis, avec une analyse automatique des sentiments des commentaires en POSITIF, NEUTRE et NÉGATIF.
